# Sahithi Mandava — Senior Full Stack .NET Developer Portfolio

This is the customized Next.js portfolio of Mandava Venkata Lakshmi Sahithi, based on the supplied resume. It highlights enterprise .NET development, accessible Angular/React interfaces, professional experience, education, and selected workplace projects.

## Run locally

1. Install Node.js (LTS recommended).
2. Open this folder in VS Code.
3. In the terminal, run `npm install` and then `npm run dev`.
4. Open `http://localhost:3000`.

## Update content

Edit the JavaScript files in `utils/data/` to change your biography, skills, employment, education, projects, and contact info. See `PERSONALIZATION_NOTES.md` for items to check before publishing. The portfolio retains its original visual layout while replacing previous-owner content. No private company source code is included.
